# Dataset attribution

The answer text in labeled_posts.csv comes from public Movies & TV Stack Exchange answers. Each row includes the author’s display name, profile URL, link to the original answer and the license shown by the Stack Exchange API. See the [site licensing policy](https://movies.stackexchange.com/help/licensing) and the [Creative Commons Attribution-ShareAlike 4.0 license](https://creativecommons.org/licenses/by-sa/4.0/).

The dataset removes HTML, media markup, and raw URLs, normalizes whitespace, and excerpts longer text and some quoted passages. It adds classification labels, decision notes, and source identifiers. Reused answer text and its adaptations in the dataset, sample interface, and demo are provided under CC BY-SA 4.0. The attribution columns and the original answer links supply the credit for individual posts.
